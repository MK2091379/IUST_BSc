# Algorithm Design

A comprehensive collection of algorithmic solutions, practical assignments, and quiz assessments developed for the **Algorithm Design** course. This repository explores foundational and advanced algorithmic paradigms, computational complexity analysis, and performance optimization implemented in **Python** and **C#**.

---

## 🛠 Tech Stack

- **Languages:** Python, C#
- **Runtimes & Compilers:** Python 3.x, Roslyn Compiler (`csc`), .NET CLI / SDK
- **Core Paradigms:** Divide and Conquer, Greedy Algorithms, Dynamic Programming (DP), Graph Traversal, Backtracking, Branch-and-Bound, Combinatorial Search

## 🚀 Getting Started

### Prerequisites
- [Python 3.8+](https://www.python.org/downloads/)
- [.NET SDK](https://dotnet.microsoft.com/download) (or Windows-bundled Roslyn `csc` compiler)

---

## 🧪 Execution Guide

### 1. Python Scripts
Run standalone Python scripts directly via the interpreter:

```bash
# Execute any script from the project root or parent directory
python <PathToScript>.py

# Example: Run HW3 Dynamic Programming solution
python HW3/Q1.py
```

---

### 2. C# Implementations (`HW4/Q4.cs`)

#### Option A: Direct Compilation with `csc`
```bash
# Compile the standalone C# file
csc "HW4/Q4.cs"

# Run the generated executable (Windows)
./Q4.exe
```

#### Option B: .NET CLI
```bash
# Run if configured as a .NET project
dotnet run --project <PathToProjectFolder>
```
