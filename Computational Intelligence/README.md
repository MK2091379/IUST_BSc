# Computational Intelligence

A comprehensive collection of implementations, algorithms, and computational experiments developed for the **Computational Intelligence** course. This repository explores foundational and metaheuristic paradigms in intelligent systems, including Multi-Layer Perceptrons (MLP) with backpropagation, Genetic Algorithms (GA) for combinatorial optimization, Fuzzy Sets and Fuzzy Inference Systems (FIS), and Particle Swarm Optimization (PSO).

---

## 🛠 Tech Stack

- **Language & Runtime:** Python 3.x
- **Interactive Computing:** Jupyter Notebook / JupyterLab
- **Scientific Computing & Visualization:** NumPy, SciPy, Pandas, Matplotlib, Seaborn
- **Core Paradigms:** Artificial Neural Networks (ANNs), Evolutionary Computation & Genetic Algorithms (GA), Fuzzy Logic & FIS, Swarm Intelligence & PSO

## 🚀 Getting Started

### Prerequisites
Ensure you have **Python 3.8+** installed on your system.

### Installation
Clone the repository and install the required dependencies:

```bash
pip install numpy pandas matplotlib seaborn scipy jupyterlab
```

### 1. Launching the Interactive Environment
